# Identité visuelle

Le code de Lab'O Noir OS est libre (GPL-3.0). Son identité visuelle ne l'est pas :

- le nom « Lab'O Noir » et « Lab'O Noir OS » ;
- le logo et les icônes (`arsenal/assets/icon.png`, `desktop/icons/`) ;
- le fond d'écran (`desktop/wallpapers/labonoir.jpg`) ;
- la charte noir et #FF1654 en tant que signature de la marque.

Tu peux les utiliser tels quels dans Lab'O Noir OS et pour en parler. Pour une version modifiée et
redistribuée (un « fork »), remplace le nom, le logo et le fond d'écran par les tiens, afin que personne
ne confonde ta version avec l'originale.
